Detailed Description

template<typename T>
class Finder< T >

La class Finder et permet guardar elements T associats a un regtangle en un espai 2d. T ha de tenir el metode get_rect(). Finder et permet rapidament comprobar quins objectes interseccionen amb un rectangle donat.
