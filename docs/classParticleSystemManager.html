Detailed Description

ParticleSystemManager is a class that manages particle systems and helps spawn them on the world.

Manages a collection of particle systems and provides functionality to spawn and render them.

This class follows the Singleton design pattern to ensure that only one instance of the ParticleSystemManager exists throughout the application. It provides methods to spawn new particle systems and render them onto a given window.
